실습 가이드

파일 확장자

파일 이름 끝의 확장자는 파일의 종류와 주로 사용하는 프로그램을 알려줍니다. 아래 예시로 자주 만나는 확장자를 살펴보세요.

Markdown (.md)

Markdown은 제목, 목록, 링크처럼 간단한 기호를 사용해 문서를 작성하는 형식입니다. README나 실습 기록에 자주 사용합니다.

편집 모드: 원본 작성

# 오늘의 실습

Markdown을 **연습합니다**.

- 파일을 저장합니다.
- 미리보기로 확인합니다.

[실습 자료](https://example.com)

보기 모드: 미리보기

오늘의 실습

Markdown을 연습합니다.

  • 파일을 저장합니다.
  • 미리보기로 확인합니다.

실습 자료

사용 프로그램: Visual Studio Code(VS Code)나 메모장으로 편집할 수 있습니다. VS Code에서는 파일을 연 뒤 Ctrl+Shift+V(macOS는 Cmd+Shift+V)로 Markdown 미리보기를 열어 보기 모드를 확인합니다. GitHub에 올린 Markdown 파일도 서식이 적용된 모습으로 볼 수 있습니다.

HTML (.html)

HTML은 웹페이지의 구조와 내용을 작성하는 형식입니다. 태그로 제목, 문단, 링크 등을 표시하며, 브라우저가 이를 웹페이지로 보여줍니다.

편집 모드: 원본 작성

<!doctype html>
<html lang="ko">
  <body>
    <h1>나의 첫 페이지</h1>
    <p>HTML을 연습합니다.</p>
  </body>
</html>

보기 모드: 브라우저 화면

나의 첫 페이지

HTML을 연습합니다.

사용 프로그램: VS Code에서 HTML 파일을 편집하고 저장한 다음 Chrome, Edge, Firefox 같은 웹 브라우저에서 열어 결과를 확인합니다. VS Code의 Live Server 확장 프로그램을 사용하면 저장할 때 브라우저 화면을 자동으로 새로 고칠 수 있습니다.

ZIP (.zip)

ZIP은 여러 파일과 폴더를 하나로 묶고 용량을 줄여 전달하기 쉽게 만든 압축 파일입니다. 내용물을 사용하려면 먼저 압축을 해제하세요.

메뉴에서 압축하고 풀기

  • Windows: 파일/폴더를 마우스 오른쪽 버튼으로 클릭하고 보내기 > 압축(zipped) 폴더를 선택합니다. ZIP 파일은 오른쪽 버튼을 클릭해 모두 압축 풀기를 선택합니다.
  • macOS: Finder에서 파일/폴더를 오른쪽 버튼으로 클릭해 압축을 선택합니다. ZIP 파일을 두 번 클릭하면 압축이 풀립니다.
  • Linux: 파일 관리자에서 오른쪽 버튼을 클릭한 뒤 압축 또는 여기에 압축 풀기 메뉴를 사용합니다. 메뉴 이름은 배포판에 따라 다를 수 있습니다.

터미널 명령으로 압축하고 풀기

macOS와 Linux 터미널에서는 zip과 unzip을, Windows PowerShell에서는 Compress-Archive와 Expand-Archive를 사용할 수 있습니다.

macOS / Linux

# 폴더를 ZIP으로 압축
zip -r 자료.zip 자료/

# 지정한 폴더에 압축 해제
unzip 자료.zip -d 자료_압축해제

Windows PowerShell

# 폴더를 ZIP으로 압축
Compress-Archive -Path .\자료 `
  -DestinationPath .\자료.zip

# 지정한 폴더에 압축 해제
Expand-Archive -Path .\자료.zip `
  -DestinationPath .\자료_압축해제

Linux에 zip 또는 unzip 명령이 없다면 배포판의 소프트웨어 관리자를 이용하거나, 파일 관리자의 압축 메뉴를 사용하세요.

이미지 파일 (.png, .jpg, .webp, .gif)

이미지 파일은 사진이나 그림을 저장합니다. 브라우저와 기본 사진 앱으로 볼 수 있고, 그림판이나 이미지 편집 프로그램으로 수정할 수 있습니다.

  • PNG: 투명한 배경을 표현할 수 있고 선명한 그림이나 화면 캡처에 적합합니다. 보통 사진보다 파일이 클 수 있습니다.
  • JPG/JPEG: 사진에 널리 쓰이며 파일 크기를 줄이는 데 유리합니다. 투명한 배경은 지원하지 않습니다.
  • WebP: 웹에서 사용하기 좋도록 용량을 줄인 형식으로, 투명 배경과 애니메이션도 지원합니다. 일부 오래된 프로그램에서는 열리지 않을 수 있습니다.
  • GIF: 간단한 애니메이션을 저장할 수 있습니다. 색상 수가 제한되어 있어 사진보다는 짧은 움직이는 그림에 적합합니다.

이미지 파일은 텍스트 편집기에서 편집하는 파일이 아닙니다. 확장자만 바꾸어도 이미지 형식이 변환되지는 않으므로, 형식을 바꾸려면 이미지 편집 프로그램이나 변환 기능을 사용하세요.
