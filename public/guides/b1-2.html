🎯 미션 핵심 목표

기획 의도 → 프롬프트 → 결과물 → 통합 편집으로 이어지는 멀티모달 제작 파이프라인을 스스로 설계하는 역량을 기른다.

가상(또는 실제) 브랜드 1개를 선택해 스토리보드를 만들고, AI 도구만을 주된 소스로 30초 이상 60초 이내의 광고 영상을 완성한다. 중요한 것은 "도구를 많이 쓰는 것"이 아니라, 왜 그렇게 의사결정했는지 설명하는 것이다.

Step 1: 브랜드/캠페인 정의

타겟 / 톤앤매너 / 차별점(USP) / 핵심 메시지 1문장

Step 2: 스토리보드 작성

씬별 필수 필드 7개 완성 + 프롬프트 수정 전/후 기록(최소 1씬)

Step 3: 멀티모달 생성

이미지 / 비디오 / 오디오 생성 AI 각 1종 이상 사용

Step 4: 통합 편집

해상도/비율/톤 정리 → 하나의 광고 영상으로 합성

Step 5: 검수·제출

스토리보드(PDF) + 광고 영상(MP4) 2종 제출

📦 최종 결과물 2종

1. 스토리보드(기획) 문서 — PDF 1개

브랜드 아이덴티티 / 캠페인 목표·핵심 메시지 / 씬 구성(씬별 필수 필드) / 사용 도구 목록

2. 광고 영상 파일 — MP4 1개

길이 30~60초 / 영상·오디오 소스는 생성형 AI 결과물이 주된 소스

💡 핵심 관점
캐릭터/화풍 불일치, 해상도·비율 혼재, 오디오 톤 미스매치, 크레딧/대기열 이슈를 미리 예측해 제작 전략을 세우는 것이 학습 포인트입니다.

  • 영상에 AI 생성 시각 요소와 청각 요소가 모두 포함되어 있는가?
  • 직접 촬영/유료 스톡 소스를 사용하지 않았음을 설명할 수 있는가?

🔍 평가질문 2: 동작 구조 및 설계

  • "기획 → 생성 → 검수 → 편집/통합" 파이프라인을 어떤 순서로 설계했는지 설명할 수 있는가?
  • 크레딧/대기열 같은 제약을 고려해 씬 수·생성 횟수·대체 도구를 어떻게 설계했는지 설명할 수 있는가?
  • 톤앤매너 일관성을 위해 에셋 규격(해상도/비율/색감)과 생성 파라미터를 어떻게 표준화했는지 설명할 수 있는가?
  • 결과 파일(이미지/영상/오디오)을 재사용 가능하도록 네이밍/정리 규칙을 어떻게 잡았는지 설명할 수 있는가?
📋 핵심 체크 포인트
• 파이프라인 설명은 "순서"뿐 아니라 왜 그 순서인지(예: 이미지→영상 변환으로 크레딧 절약)를 들어야 합니다.
• 대체 도구는 이미지/비디오/오디오 각각 1개 이상 준비한 것이 좋습니다(도구명 기록만으로도 OK).
• 파일 네이밍은 씬 번호·콘텐츠 유형을 포함한 일관된 규칙(예: scene01_keyvisual.png)이 권장됩니다.

🔍 평가질문 3: 핵심 기술 원리 적용

  • Text-to-Image와 Image-to-Video(또는 Text-to-Video)의 차이와, 프로젝트에서 어떤 기준으로 선택했는지 설명할 수 있는가?
  • 도구를 선택할 때 품질/제어/속도/비용 중 무엇을 우선했고, 그 이유를 설명할 수 있는가?
  • 프롬프트 A→B로 바꾸며 결과가 어떻게 달라졌는지와 그 변화가 발생한 원인을 설명할 수 있는가?
  • 캐릭터/스타일 일관성을 위해 어떤 제어 방법(레퍼런스 고정, 파라미터, 후처리 등)을 사용했는지 설명할 수 있는가?
💡 심층 인터뷰 질문 예시
Q1: "같은 스토리보드를 다른 도구로 만들면 무엇이 가장 달라질까요?"
• 품질: 모델별 학습 데이터 차이로 디테일·질감 수준이 다름
• 제어: 이미지-투-비디오는 구도/구성이 통제되고, 텍스트-투-비디오는 자유도가 높지만 변수가 큼
• 속도: 도구별 렌더링/대기열 시간이 다름 (크레딧·대기열 비용)
• 비용: 영상 생성은 이미지보다 크레딧 소모가 훨씬 큼 → 이미지 단계에서 확정 후 변환

Q2: "프롬프트 A→B로 바꾸며 결과가 왜 달라졌나요?"

• 부정/제한 표현(~~하지 않는, 실루엣 중심)이 과장된 디테일을 억제
• 스타일 키워드(사이버펑크, 네온) 위치가 톤에 영향
• 결과 변화는 스크린샷/파일로 남겨 비교 근거로 제시

"스토리보드를 왜 먼저 만드나요?"
영상 생성은 크레딧 소모가 크므로, 이미지 단계에서 스토리보드를 최대한 확정해 재생성 횟수를 줄입니다. 또한 씬별 목표·구성을 사전 확정해 캐릭터/화풍 일관성과 메시지 밀도를 관리할 수 있습니다.
"이미지-투-비디오가 뭔가요?"
정지 이미지에 모션(패닝/줌/루프 등)을 부여하는 방식입니다. 텍스트-투-비디오 대비 구도·구성이 통제되어 스토리보드 구현에 적합하고, 크레딧 효율도 높습니다.
"같은 요구인데 도구마다 결과가 왜 다를까요?"
모델마다 학습 데이터·파라미터 해석이 달라 톤·디테일·구도가 다릅니다. 품질/제어/속도/비용 축으로 비교하고, 프로젝트 목적에 맞는 도구를 선택하는 것이 핵심 역량입니다.
"캐릭터 일관성은 어떻게 유지하나요?"
Character/Style Reference(cref/sref) 또는 ControlNet 계열 제어 기능을 활용하고, 동일 스타일 레퍼런스를 고정합니다. 어떤 파라미터/레퍼런스를 고정했는지 스토리보드에 기록해야 발표에서 설명할 수 있습니다.
"오디오는 왜 따로 만드나요?"
영상 톤에 맞는 BGM/효과음/나레이션을 TTS·음악 생성 AI로 제작합니다. 톤앤매너 미스매치를 방지하려면 브랜드 아이덴티티에 오디오 가이드라인을 먼저 명시하세요.

⚠️ 흔한 실수

  • 도구 나열만 하고 선택 근거 없음
    ✗ "Midjourney, Runway, Suno를 썼어요"
    ✓ "키 비주얼 톤 통제를 위해 이미지에 Midjourney, 구도 고정을 위해 이미지-투-비디오에 Runway를 선택"

🔧 문제 해결 가이드 (FAQ)

Q1. 캐릭터/화풍이 씬마다 달라요
✅ 해결방법
• Character Reference(cref) / Style Reference(sref) 또는 ControlNet 계열 제어 기능 활용
• 동일 스타일 레퍼런스 이미지를 모든 씬에 고정
• 프롬프트 전반부(스타일 정의)를 모든 씬에서 동일하게 유지
• 어떤 파라미터/레퍼런스를 고정했는지 스토리보드에 기록 (발표 시 설명 필수)
Q2. 영상 생성 크레딧이 부족해요
💡 크레딧 절약 전략 (최소 1개 선택)
1. 씬 수 축소: 6씬 → 4씬으로 줄이고 메시지 밀도를 높이기
2. 정지 이미지 + 짧은 모션: 패닝/줌/루프 중심으로 구성하기
3. 스타일 레퍼런스 고정: 재생성 횟수를 줄이기
※ 영상 변환 전, 이미지 생성 단계에서 스토리보드를 최대한 확정하세요.
Q3. 도구 대기열/플랜 제한에 막혔어요
✅ 대응 방법
• 이미지/비디오/오디오 각각 대체 도구를 1개 이상 준비 (도구명만 기록해도 OK)
• 예: 비디오 생성/변환 대안(Pika, Kling 등), 오디오/TTS 대안(여러 생성 도구 중 택)
• 대기열 예상 시간을 스토리보드 일정에 반영하고, 막힌 도구는 대안으로 즉시 전환
Q4. 해상도·화면 비율이 제각각이에요
✅ 표준화 방법
• 생성 단계에서 에셋 규격(1080p, 16:9 등)을 사전 표준화
• 톤앤매너 일관성을 위해 색감 파라미터 통일
• 통합 편집에서 크롭/리사이즈/색보정으로 최종 정리
• 플랫폼별 비율(보너스 3)이 필요하면 동일 스토리보드 기준으로 재구성
Q5. 오디오 톤이 영상과 안 맞아요
✅ 톤앤매너 맞추기
• BGM/효과음/나레이션의 톤앤매너 가이드라인을 브랜드 아이덴티티에 명시
• 오디오 레벨 조정은 편집 도구로 최종 통합 단계에서 처리
• 오디오 대안 도구를 1개 이상 준비해 미스매치 시 교체
Q6. 영상 길이가 30초 미만/60초 초과예요
✅ 길이 조절
• 미션 개요 탭의 영상 길이 계산기로 씬별 합계를 먼저 검증
• 30초 미만: 씬 추가 또는 씬 길이 조정 / 60초 초과: 씬 축소(6→4)
• 최종 3~5초는 브랜드 인지 장치(로고/브랜드명/슬로건/CTA)로 확보
Q7. 저작권·윤리 이슈가 걱정돼요
⛔ 금지 사항
• 직접 촬영, 유료 스톡 영상 소스 사용 금지 (모든 소스는 생성형 AI 결과물)
• 딥페이크, 혐오/선정성/폭력 등 유해 콘텐츠 생성 금지
• 생성 로그를 남겨 "AI 생성 결과물"임을 설명할 수 있도록 준비
