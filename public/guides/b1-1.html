B1-1: LLM 기반 업무 자동화

퍼실리테이션 인터랙티브 가이드 | AI Tools Essentials | 학습난이도: 1

🎯 미션 핵심 목표

LLM의 확률적 생성 원리를 이해하고, 프롬프트 엔지니어링을 통해 원하는 텍스트 결과물을 정교하게 제어하는 기술을 익힌다.

Step 1: LLM 3종 이상 비교·선정

동일 업무 과업으로 모델별 성능을 평가 축 기반으로 비교

Step 2: 페르소나 및 시스템 프롬프트 설계

안전장치·출력 규칙·사실 검증 규칙 포함

Step 3: Few-shot 예시 + v1→v2 개선

단계적 추론 유도 기법 적용 및 전후 비교

Step 4: 환할 검증 (5문제 이상)

Pass/Fail 기준 명확히 정의

Step 5: 10턴 이상 대화 로그

조건 변경·추가 정보 반영·문맥 유지 검증

완료! 결과물 3종 제출

모델 비교 보고서 + 시스템 설계문서 + 실행 로그

📦 최종 결과물

1. LLM 모델 비교·선정 보고서
2. 시스템 설계 문서
3. 실행 로그 (10턴 이상)

상세 체크리스트·채점 루브릭·문제 해결은 상단 탭에서 확인하세요.

📦 결과물 체크리스트

  • 모델 비교 보고서 (3종 + 평가 축 4개+)
  • 업무 과업 정의
  • 페르소나 + 시스템 프롬프트
  • Few-shot 예시 (3개+)
  • 환할 검증 (5문제+)
  • 10턴 대화 로그

🔍 평가 가이드

기능 동작, 설계 구조, 환할 이해도, 심층 인터뷰를 기준으로 평가합니다.

🎓 진행 팁

5시간 커리큘럼으로 모델 비교 → 과업 정의 → 프롬프트 설계 → Few-shot → 환할 검증 → 10턴 로그 순으로 진행하세요.

⚖️ 채점 루브릭 (100점)

모델 비교 20 / 업무 정의 15 / 프롬프트 15 / Few-shot 15 / 환할 15 / 10턴 로그 20

🔧 문제 해결

무료 모델(Claude 3.5 / GPT-4o / Gemini)로 비교 가능합니다. 프롬프트는 100~200단어 이내로 유지하세요.
