1먼저 이것만 알고 시작하세요

이 미션에서 "당신이 직접 정해야 하는 판단"은 딱 네 가지입니다. 나머지는 AI가 도와줘도 됩니다.

직접 써야 하는 판단 4종 (AI 대행 금지) ① 서비스 이름·한 줄 소개·톤앤매너
② 씬마다 도구를 고른 이유(사용 목적)
③ 프롬프트를 왜 바꿨는지
④ 10초에 넣지 않기로 한 장면과 그 기준
미션이 확인하려는 것은 "도구를 많이 썼는가"가 아니라 왜 그렇게 정했는가입니다. 이 네 개를 AI가 대신 쓰면 판단 과정이 사라집니다.
AI에게 맡겨도 되는 일 내레이션 문안 초안, 화면 구성 문구 다듬기, 프롬프트 초안 영어로 바꾸기, 표 정리, 파일명 규칙 예시, 작업 기록 오타 정리. 단, 프롬프트 원문과 출력 결과 요약은 실제로 넣은 그대로 적어야 합니다.
제일 중요한 규칙 하나 프롬프트는 생성 직후에 그대로 복사해 메모하세요. 나중에 기억해서 다시 쓰면 그건 "원문"이 아니라 "추정"이 됩니다. 출력 결과 요약과 생성 파일명도 같은 시각에 적어 두면 씬 10개 필드를 나중에 다시 채울 필요가 없습니다.
문서 충돌 주의 — 시작 전에 꼭 확인 B1-2/mission-details.md는 5~10초라고 하지만, 같은 폴더의 guide.html은 30~60초라고 씁니다. 이전 규격이 남아 있는 것이므로 첨부된 미션 문서(5~10초)를 기준으로 하세요. 퍼실리테이이터에게도 한 번 알려주면 좋습니다.

2용어 8개만 잡으면 과제가 보입니다

컴퓨터 지식이 아니라 어휘 문제입니다. 아래 8개를 자기 말로 설명할 수 있으면 문서가 읽힙니다.

① 서비스 정체성

이름 + 한 줄 소개 + 톤앤매너. 광고의 모든 결정이 여기서 나옵니다. 다음 단계 서비스로 이어지므로 직접 정합니다.

예: 길눈 / 처음 가는 동네에서 오늘 뭘 할지 3개만 골라 주는 서비스 / 친구가 옆에서 알려 주는 말투

② 씬과 스토리보드

씬 = 광고를 이루는 한 장면. 스토리보드 = 씬마다 무엇을 보여줄지 적은 설계도.

10초 광고라면 3~4씬, 각 2~3초가 현실적입니다

③ 프롬프트와 카테고리

AI에게 주는 지시문. 완성한 프롬프트 3건 이상에 이미지/영상/오디오 중 카테고리를 붙여야 합니다.

예: [이미지 생성] 저채도 초록 배경, 종이 질감 카드 세 장

④ 텍스트 → 이미지

글을 넣어 그림을 받는 방식. 구도와 스타일을 여기서 거의 확정합니다. 크레딧이 영상보다 훨씬 저렴합니다.

예: "저채도 초록 배경, 손가락이 카드에 닿기 직전, 클로즈업"

⑤ 이미지 → 영상

정지 이미지에 줌·패닝 같은 짧은 움직임을 주는 방식. 텍스트→영상보다 구도가 통제되고 재생성이 적습니다.

영상 생성 도구로 세며, 이미지를 움직이기만 해도 충족됩니다

⑥ 오디오 생성 (TTS / BGM)

목소리·효과음·배경음악을 따로 만드는 것. 음성/효과음/BGM 중 하나 이상이면 충족입니다.

속도가 너무 빠르면 0.9배로 낮춰 다시 받고, 수정 이유를 기록

⑦ 화면 비율과 짧은 변

짧은 변 = 가로세로 중 짧은 쪽 픽셀. 720px 이상이면 통과. 비율은 씬마다 하나로 고정해야 합니다.

1280×720 → 짧은 변 720 → 충족 / 1080×1920 → 짧은 변 1080 → 충족

⑧ 톤앤매너 일관성

색감·화풍· 말투를 씬 전체에서 맞추는 일. 같은 레퍼런스 이미지와 같은 스타일 키워드를 고정하면 쉬워집니다.

프롬프트 앞부분(스타일 정의)을 모든 씬에서 똑같이 씁니다

＋ 헷갈리기 쉬운 것

기승전결 = 문제 제시 → 전개 → 전환 → 해결. 가치 전달 = 누구에게 어떤 가치를 주는지. 둘 중 하나만 표기하면 됩니다.

캠페인 목표는 인지 / 전환 / 리텐션 중 하나. 10초 광고는 '인지'가 가장 무난합니다.

위에서부터 순서대로 하세요. 체크한 내용은 이 브라우저에 저장됩니다. (탭을 닫아도 유지)

4서비스 구상 — 여기서 제일 많이 멈춥니다

광고 대상은 다음 단계에서 만들 여행지 추천 웹 서비스로 고정입니다. "아직 서비스가 없는데요?"라고 막히지만, 상상해서 이름과 성격만 정하면 됩니다.

바로 참고할 수 있는 정체성 조합 (그대로 쓰지 말고 섞어 보세요)

느린 동네

"관광지 대신 동네 하나를 천천히 고르는 서비스"

톤: 느린 말투, 느낌표 없음, 흙색·저채도 초록

세 개만

"처음 가는 도시에서 오늘 할 일 3개만 골라 주는 서비스"

톤: 친구가 옆에서 알려 주는 말투, 권유형

오늘길

"지금 있는 곳에서 도보 15분 안의 길을 추천하는 서비스"

톤: 담백하고 짧게, 파란색·흰색 중심

이름과 톤은 다음 단계에서 다시 손볼 수 있습니다. 다만 지금 정한 것이 광고와 서비스 모두에 이어지므로 마음에 드는 것으로 골라 두세요.

절대 쓰면 안 되는 소재 실존 인물과 실존 상표는 생성 대상으로 금지(초상권·상표권). 딥페이크·혐오·선정성·폭력도 금지. 직접 촬영한 사진과 유료 스톡도 금지입니다. 참고용 레퍼런스 이미지는 괜찮지만, 화면에 넣었다면 어느 씬인지 작업 기록에 밝혀야 합니다.

정체성 7항목 (한 문단으로)

항목적는 내용예시
서비스 이름 / 소개이름과 한 줄 설명길눈 / 동네에서 오늘 할 일 3개만 골라 주는 서비스
톤앤매너말투 + 태도 + 색감 + 오디오 톤친구가 알려 주는 말투, 느낌표 없음, 저채도 초록과 모래색
대상 고객이 광고를 누가 보면 좋나여행은 가고 싶은데 계획 세우기가 귀찮은 20~30대
차별점(USP)다른 서비스와 무엇이 다른가목록이 20개가 아니라 3개만 나온다
캠페인 목표인지 / 전환 / 리텐션 중 하나인지 (서비스 이름을 기억하게 하는 것)
핵심 메시지한 문장고르는 데 오래 걸리지 않는다
씬 나누기 쉬운 공식 씬 1 = 문제("어디 갈지 고르다 시간 다 보냄") → 씬 2 = 전개("딱 3개만 추천") → 씬 3 = 해결 + 브랜드("이름 + 슬로건 + 행동 유도"). 이 3개면 7~9초가 되고, 기승전결 표기도 자연스럽게 됩니다.

6

편집 도구로 새 소재를 만들거나, 실존 인물·상표를 넣음

편집은 자르기·자막·색보정·음량·비율 조정까지만 허용됩니다. 실존 인물/상표와 직접 촬영·유료 스톡은 금지입니다.

8막힐 때 FAQ

실제로 가장 많이 나오는 질문들입니다. 접어두었으니 필요한 것만 펼쳐 보세요.

가이드는 30~60초라는데 미션은 10초 이내라고요. 뭘 믿죠?
첨부된 B1-2/mission-details.md가 기준입니다. guide.html은 이전 규격(30~60초, 1080p 권장)을 그대로 담고 있습니다. mission-feedback.md도 "10초 이내"라고 쓰고 있어 5~10초 쪽이 두 문서에서 일치합니다. 퍼실리테이이터에게 문서 충돌을 알리고, 5~10초 / 짧은 변 720px 이상으로 만드세요.
설치해야 할 프로그램이 있나요?
없습니다. 생성 도구 4종(글·이미지·영상·오디오)과 편집 도구 1종 모두 브라우저에서 열립니다. 코드도 필요 없습니다. 유일하게 손이 가는 곳은 PDF로 내보내기와 GitHub 웹 업로드뿐입니다.
프롬프트는 영어로 써야 하나요?
아닙니다. 한국어로도 동작합니다. 도구에 따라 영어가 더 안정적이면 AI에게 한국어 초안을 영어로 다듬어 달라고 하면 됩니다. 단, 스토리보드에 적는 입력 프롬프트 원문은 실제로 넣은 문구여야 합니다. 다듬은 영어를 넣었다면 그 영어를 적으세요.
손가락이 6개 나왔어요 / 씬마다 화풍이 달라요
둘 다 흔합니다. 손은 "손가락은 5개, 손은 화면의 5분의 1 이내"처럼 구체 제약을 추가해 다시 생성하세요. 화풍은 같은 레퍼런스 이미지와 같은 스타일 키워드를 모든 씬에 고정하고, 프롬프트 앞부분을 똑같이 쓰면 해결됩니다. 이 재생성 과정을 수정 전/후 로그로 그대로 쓰면 요구사항도 충족됩니다.
AI가 글자를 이상하게 써요. 로고는 어떻게 넣죠?
글자 생성은 생성 도구의 약점이라 자주 깨집니다. 브랜드명·슬로건·CTA는 편집 도구의 자막 기능으로 얹으세요. 자막은 허용된 편집 범위(컷 편집·자막·색보정·음량·비율) 안에 있습니다. 마지막 3~5초에 이 자막이 보이면 충족입니다.
내가 찍은 사진이나 실존 관광지를 넣어도 되나요?
직접 촬영 소재와 유료 스톡은 금지입니다. 실존 인물과 상표도 생성 대상으로 쓰면 안 됩니다. 여행지 장소 자체는 참고로 쓸 수 있지만, 결과 화면에 넣은 이미지가 생성 결과가 아니라면 어느 씬에 넣었는지 작업 기록에 밝히세요. 참고용 레퍼런스 이미지를 도구에 넣는 것은 제한되지 않습니다.
무료 크레딧이 다 떨어졌어요 / 대기열이 길어요
이미지·영상·오디오 각각 대체 도구를 1개 이상 미리 적어 두고 즉시 전환하세요. 크레딧을 아끼려면 ① 이미지 단계에서 스토리보드를 최대한 확정한 뒤 영상으로 넘어가고, ② 씬 수를 3개로 줄이고, ③ 스타일 레퍼런스를 고정해 재생성을 줄이면 됩니다. 막힌 사실과 대안을 작업 기록에 남기면 오히려 좋은 근거가 됩니다.
짧은 변 720px이 뭔가요?
가로세로 중 짧은 쪽 픽셀입니다. 1280×720이면 720 → 충족, 1080×1920이면 1080 → 충족, 1080×1080이면 1080 → 충족입니다. 씬마다 비율이 섞였다면 편집 단계에서 크롭·리사이즈·여백 덧대기로 하나로 맞추면 됩니다(허용 범위).
오디오가 영상보다 길어서 파일이 늘어났어요
정상 현상입니다. 미션에도 "오디오가 영상보다 길면 파일이 그만큼 늘어난다"고 적혀 있습니다. 오디오 트랙을 영상 길이와 같게 자르고, 최종 파일의 실제 재생 시간을 스토리보드에 적으세요. 5~10초 안에 들어오면 됩니다.
작업 기록은 몇 줄 써야 하나요? "프롬프트 수정"이라고만 써도 되나요?
건수와 서식은 자유입니다. 시작할 때·막혔을 때·끝낼 때 한 줄씩만 써도 충족합니다. 다만 종류만 적으면 안 됩니다. "씬 3 프롬프트에 '손은 화면의 5분의 1 이내'를 더해 2차 생성"처럼 무엇을 어떻게 했는지가 보여야 합니다. 여러 작업을 한 줄에 몰아 쓰지 마세요.
보너스 과제는 꼭 해야 하나요?
아닙니다. 게다가 4개를 모두 완료해야만 크레딧이 지급됩니다(부분 점수 없음). 비전공자에게는 2번(다른 도구로 같은 씬 재제작)과 3번(비율 버전 2개)이 비교적 쉽습니다. 4번(Google Apps Script API)은 "키를 발급하지 못한 사실"이나 "오류 응답"도 기록으로 인정되지만, 본편 2개 파일을 끝낸 뒤 여유가 있을 때만 손대세요.
소요 시간은 얼마나 걸릴까요?
미션 표준 학습시간은 40시간이지만, 이 가이드의 9단계를 따라가면 핵심 산출물은 약 5~6시간에 완성됩니다. 오래 걸리는 구간은 ①도구 가입·무료 조건 확인 ②씬 10필드 기록 ③잘려 나간 오디오와 길이 맞추기입니다. 반대로 스토리보드 씬 나누기와 프롬프트 작성은 생각보다 빨리 끝납니다.
마지막으로 — 이 페이지의 기준 mission-details.md의 5~10초 / 짧은 변 720px 이상을 따릅니다. guide.html의 30~60초는 구버전입니다. 씬마다 10필드, 수정 전/후 1건, 카테고리 3건, 도구 4종, 작업 기록 한 항목씩 — 이 다섯 개만 기억해도 대부분의 감점을 피합니다.
