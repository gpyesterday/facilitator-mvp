M1-1: 숫자 데이터를 AI와 같이 보며 흐름과 패턴 찾기

퍼실리테이션 인터랙티브 가이드 | AI 응용 | 선택 심화 | 학습난이도: 3

🎯 미션 핵심 목표

시간에 따라 변하는 데이터를 정제하고 시각화한 뒤, 그래프에서 확인한 사실과 가능한 해석을 구분하여 근거 기반 인사이트로 설명합니다. AI는 분석을 돕지만 최종 판단과 검증은 학습자가 수행합니다.

Step 1: 분석 주제·시계열 데이터 선정

관심 질문과 연결된 데이터를 고르고, 출처·기간·단위·관측 수(100개 이상)를 확인합니다.

Step 2: 분석 질문 3개 이상 정의

추세, 급격한 변화, 기간·요일별 차이 등 데이터로 답을 확인할 수 있는 질문을 만듭니다.

Step 3: 데이터 점검·정제·분석

기간, 컬럼, 결측·이상치를 확인하고 이동평균·변화율·구간 통계 등 기법을 2가지 이상 적용합니다.

Step 4: 시각화·인사이트 도출

그래프 2개 이상(권장 3개 이상)을 만들고, 수치·구간 근거가 있는 인사이트를 3개 이상 정리합니다.

Step 5: 리포트·코드·재현 방법 제출

REPORT.md, Python 코드/노트북, 데이터 출처·실행 방법·AI 사용 로그를 저장소에 정리합니다.

완료! 패턴을 자기 말로 설명

관찰(Fact) → 원인 가설(Why) → 행동(Action), 반례와 한계까지 설명할 수 있습니다.

1. 분석 리포트 (REPORT.md)
주제·질문·데이터 설명·시각화·인사이트·결론/한계·AI 사용 로그

2. Python 분석 코드
Jupyter Notebook(.ipynb) 또는 Python 스크립트(.py)

3. 시각화와 재현 정보
그래프 이미지 또는 노트북 출력, 실행 방법, 라이브러리·데이터 출처 정보

필수 조건
100개 이상 시계열 관측값 · 분석 질문 3개 이상 · 분석 기법 2가지 이상 · 그래프 2개 이상 · 근거 있는 인사이트 3개 이상

🧭 퍼실리테이터의 초점

  • 먼저 질문을 정하고, 그 질문에 맞는 데이터를 고르게 합니다.
  • 그래프에서 직접 확인한 사실과 원인에 대한 추측을 구분하게 합니다.
  • AI 답변을 정답으로 취급하지 않고, 코드 실행·표본 대조·재계산으로 검증하게 합니다.
  • 인과관계 단정 대신 대안 가설·반례·추가로 필요한 데이터를 묻습니다.

📚 학습 목표 분석: 지식 · 기술 · 이해

지식: 알아야 할 것

  • 시계열 데이터의 시간축·관측 간격, 추세·계절성·노이즈
  • 결측치·이상치와 이동평균·변화율·구간 통계의 의미
  • 시각화의 축·단위·집계 기준과 Python 분석 흐름
  • 데이터 출처, 라이선스, 재현 가능한 실행 정보

기술: 해낼 수 있어야 할 것

  • 시계열 데이터 100개 이상을 찾고 분석 질문 3개 이상 정의하기
  • 데이터를 점검·정제하고 처리 기준을 설명하기
  • 기법 2개 이상과 그래프 2개 이상을 적용해 결과 비교하기
  • 관찰 근거가 있는 인사이트를 리포트와 코드로 재현하기

이해: 설명할 수 있어야 할 것

  • 그래프가 보여주는 사실과 원인에 대한 가설은 다르다는 점
  • 분석 질문·집계 단위에 따라 패턴과 결론이 달라질 수 있다는 점
  • 적용한 기법이 무엇을 드러내고 무엇을 놓칠 수 있는지
  • AI 결과는 코드·수치·표본으로 검증하고 최종 해석은 스스로 책임진다는 점
퍼실리테이션 목표
각 항목을 대신 설명하기보다, 학습자가 자신의 데이터와 분석 결과를 근거로 설명하도록 질문을 연결합니다.

🧠 분석 사고의 기본 구분

구분의미학습자 문장 예시
관찰 (Fact)자료나 계산으로 재현 가능한 값·구간“7일 이동평균이 3월 둘째 주부터 상승했고, 해당 주 평균은 전주보다 8% 높다.”
해석 (Why)관찰을 설명하는 가설. 데이터만으로 확정할 수 없는 이유를 표시“행사 영향일 수 있지만, 행사 정보가 없어 원인으로 단정할 수 없다.”
행동 (Action)의사결정 또는 다음 검증 단계“행사 일정과 유입 경로 데이터를 추가해 같은 패턴이 반복되는지 확인한다.”

전체 항목
  • 시계열 데이터와 출처

    시간 기준으로 정렬된 100개 이상 관측값, 데이터 기간·단위·출처(가능하면 라이선스/수집 방법 포함)

  • 분석 질문 3개 이상

    질문이 명확하며, 분석 결과나 그래프에서 답을 확인할 수 있음

  • 데이터 점검·정제 기준

    기간·컬럼·결측치·이상치 확인, 처리 여부와 그 이유가 설명됨

  • 시계열 분석 기법 2가지 이상

    예: 이동평균, 변화율, 구간별 통계, 변동성/표준편차, 요일·월별 집계

  • 시각화 2개 이상 (권장 3개 이상)

    리포트에서 이미지/출력 링크가 정상 동작하고 시간축·집계 단위가 분명함

  • 인사이트 3개 이상

    각 인사이트에 그래프에서 확인한 수치·기간 등 구체적인 관찰 근거가 있음

  • 코드와 재현 방법

    .ipynb 또는 .py, 필요한 라이브러리/버전, 실행 순서나 명령, 데이터 확보 방법 제공

  • 결론·한계·AI 사용 로그

    한계와 다음에 검증할 데이터, AI 사용 작업·이유·검증 방법을 기재

📝 리포트 구성 예시

  1. 주제와 선정 이유 — 무엇을 알고 싶은지
  2. 분석 질문 — 최소 3개, 데이터에서 확인 가능한 형태
  3. 데이터 설명 — 출처, 기간, 관측 수, 컬럼과 단위, 결측/이상치
  4. 분석 방법 — 적용 기법 2개 이상과 선택 이유
  5. 결과 및 시각화 — 그래프 최소 2개, 각 그래프의 핵심 관찰
  6. 인사이트 — Fact → Why(가설) → Action 형식으로 3개 이상
  7. 결론과 한계 — 다른 기간·집계 단위·외부 요인 등 반례 포함
  8. AI 사용 로그 — 사용 작업, 사용 이유, 검증 방법

일별 판매량요일별 차이나 급격한 변동이 있는가?일별 추이, 요일별 평균, 변화율

데이터 적합성 확인
제공된 부산 방문동향 표는 국가별 누계 순위 형태입니다. 시간별 관측값 100개 이상을 확보할 수 있는지 먼저 확인하고, 현재 표만으로 조건을 충족한다고 간주하지 마세요.

🔍 구두 평가 질문

완성된 결과를 대신 설명하지 말고, 학습자가 근거와 선택 이유를 스스로 말하도록 기다립니다.

  • 이 시계열은 100개 이상의 데이터 포인트를 포함하나요? 기간과 관측 단위는 무엇인가요?
  • 분석 질문을 3개 이상 제시하고, 각 질문에 답한 결과를 가리킬 수 있나요?
  • 기법 2가지 이상과 시각화 필수 2개(권장 3개 이상)가 결과물에 포함되어 있나요?
  • 인사이트가 3개 이상이며, 각 주장에 수치나 관찰 구간이 있나요?
  • GitHub 저장소에서 코드, 리포트, 데이터 또는 출처·실행 방법을 확인할 수 있나요?
  • 데이터 로딩 → 정제 → 분석 → 시각화 흐름을 단계적으로 설명해보세요.
  • 결측치나 이상치를 어떤 기준으로 처리했나요? 제외/대체하지 않았다면 왜인가요?
  • 일·주·월 등 집계 단위는 무엇이고, 그 단위가 질문에 적절한 이유는 무엇인가요?
  • 이동평균이나 변화율을 적용해 무엇을 더 잘 보려고 했나요?
  • 추세·계절성·노이즈 중 하나를 그래프에서 어떻게 구분했나요?
  • AI가 만든 코드나 해석을 어떻게 검증했나요? 직접 확인한 한 가지 사례는 무엇인가요?
  • 인사이트 하나를 관찰(Fact) → 원인(Why) → 행동(Action) 순서로 설명해주세요.
  • 다른 기간이나 집계 단위, 외부 변수를 고려하면 결론이 달라질 수 있나요?
  • 현재 분석의 한계와 다음에 수집·검증할 데이터를 제안해주세요.
  • AI 사용 이유·검증 기록을 근거로, 핵심 결론을 본인 말로 다시 설명해보세요.

🔧 문제 해결 가이드 (FAQ)

✅ 점검 순서
먼저 날짜/시간 열과 관측 단위를 확인합니다. 기간을 넓히거나 더 세밀한 공개 데이터로 바꾸되, 중복 행을 늘려 조건을 맞추지는 않습니다. 집계된 단면 표만 있다면 시계열 원자료를 추가로 찾도록 안내합니다.
💡 판단을 기록하기
결측이 데이터 수집 누락인지 실제 0인지 확인합니다. 이상치는 오류인지 실제 급변인지 원자료와 맥락을 확인하세요. 삭제·대체가 결론에 미치는 영향을 가능하면 전후 비교하고, 처리하지 않은 경우에도 이유를 명시합니다.
✅ 관찰에서 시작
“전체적으로 어떤가요?” 대신 시작·끝 값, 최대/최소 구간, 전후 차이, 이동평균·변화율을 수치로 묻습니다. 관찰을 먼저 문장으로 쓴 다음 가능한 원인과 추가로 확인할 자료를 구분하게 합니다.
📋 검증 전략
코드 블록을 단계별로 실행하고, 작은 표본에서 원자료를 직접 계산해 결과를 비교합니다. 날짜 정렬, 분모·이동 창 크기, 결측 처리와 그래프 축을 점검하세요. AI에게 작성한 가정·수식 설명을 요청하되, 최종 근거는 코드와 데이터에서 재확인합니다.
💡 대안 가설과 한계
시간적 동행만으로 인과가 증명되지는 않습니다. 외부 변수, 다른 기간, 다른 집계 단위에서 같은 패턴이 보이는지 질문합니다. 예측 과제는 보너스이며, 단순 기준선·가정·오차·한계를 함께 설명하도록 합니다.
