🎯 미션 핵심 목표

입력한 날짜를 바탕으로 LLM의 구조화된 추천을 만들고, 그 추천 지역을 장소 검색에 연결한 뒤 데이터와 Markdown 여행 리포트로 저장한다.

Step 1: 실행 입력과 설정 점검

Python 3.10+, CLI 날짜 인자, API 제공자와 환경변수 키 설정을 확인한다.

Step 2: 날짜 → 1차 추천 JSON

recommended_city, weather, events, reason의 키와 타입을 검증한다.

Step 3: 추천 지역 → 맛집 검색

Kakao Local 또는 Naver Local 응답을 필요한 필드로 정리한다.

Step 4: 데이터 결합 → 여행 리포트

추천, 날씨, 행사, 맛집, 1일 일정, 오류 요약을 Markdown으로 작성한다.

완료: 결과 저장과 설명

results/의 JSON·Markdown과 README 실행 안내를 확인하고 흐름을 설명한다.

📦 최종 결과물 3종

1. CLI 프로그램
argparse로 날짜를 받고 진행 상황과 저장 위치를 출력

2. 실행 결과
results/ 안에 1차 추천·맛집 결과·errors JSON과 최종 Markdown

3. README.md
개요, 실행법, 키 설정, 결과 확인 및 키 보호 안내

🔗 데이터 흐름 한눈에 보기

--date YYYY-MM-DD
       ↓
LLM 추천 → JSON 파싱·스키마 검증
       ↓ recommended_city
장소 API → 맛집 리스트 (0건이어도 계속)
       ↓
LLM 최종 작성 → results/*.md + results/*.json
